## 四、新增模块接入清单（通用做法）

1. `src/menu.js`：`MENU_NODES` 登记节点（id 全局唯一、path、permission `<mod>.<page>.view`）
2. `src/router.js`：`ROUTES` 加 lazy 路由（crumb/module/title/permission）；旧路径如需兼容加 `LEGACY`/正则
3. 页面组件：资金组页面照 `Dashboard.jsx` 的 SECTIONS + `useDragLayout(pageLayoutKey(...))` + `<DragGrid layout="stack">` 模式
4. 数据键：新模块自选前缀登记进 `store.js` KEYS；**必须**同步登记 `SettingsPage.jsx` 的 `*_DATA_KEYS`（导入导出/清空才覆盖）
5. 首页卡片：`src/widgets/registry.js` 登记一条 `{id,title,icon,permission,el}`
6. 样式：页面级样式进对应 scoped CSS（wb-fund.css / wb-boards.css），全局件进 wb-shell.css
7. 文档：README.md 模块清单 + 使用说明.md 操作说明 + 本路线图状态列

## 五、数据安全提醒

全部数据存浏览器 localStorage：**清浏览器站点数据 = 全部丢失**。第一期已加「备份提醒」widget（>7 天未导出提醒 + 一键导出）。建议每周固定一天到设置页导出 JSON 存档。
